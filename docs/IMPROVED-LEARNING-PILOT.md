# Owner-started improved learning pilot

Notebook 17 prepares a 512-game comparison starting from the completed 2,408-game checkpoint. It does not reset the network. The explicit offline preparation tool verifies the exact parent and source hashes, preserves all model tensors, Adam moments, action/shuffle/opponent RNGs, seeds, counters and archived opponents, and writes a new immutable folder. Only Adam's configured learning rate changes. The original run and receipts remain untouched.

Before any learning, the owner's launch evaluates the preserved model. It then performs a bounded 128-step supervised warm-up on 24 scripted public engine positions (six basic skills, four variants). These are tactical examples, not expert game demonstrations or a general solution to Hearthstone. Multiple equivalent legal placements are accepted. Accuracy and answer probabilities are recorded before and after lessons. A full resume checkpoint records lesson completion so a normal resume does not repeat the warm-up. No lesson, PPO update or evaluation game runs during imports/preflight.

PPO collects 64 games per batch, covering a complete ordered deck/seat/opening-seat schedule cycle. Minibatches contain 64 decisions and Adam's learning rate is 0.0001, down from 0.0003. The four-epoch limit and KL threshold 0.02 remain safeguards, not a mandate to force all epochs. Half the games use the visible-information heuristic, a quarter the frozen current learner and a quarter archived neural opponents. These are competent baselines relative to random play, not expert players. Checkpoints save every 64 games.

The trainer now reports the actual KL that triggered stopping, complete-rollout KL after updates, unique-sample coverage, effective passes, completed epochs, policy clipping frequency, normalized entropy, gradient clipping frequency and value explained variance. The curriculum and mixture are candidate improvements; strength gains must be established by the owner's pilot rather than assumed.

Evaluation uses 128 balanced cases against each of four named opponents: heuristic, initial neural, 400-game neural and pre-change 2,408-game neural. It runs before learning and after 512 training games. The new monitoring seed set is separate from training and earlier monitoring. Its repeated use still makes it validation, not an untouched final test. Lesson assessments are also saved with evaluation reports. Compare per-opponent/per-deck results, uncertainty, safety failures and learning diagnostics before increasing the budget. Do not select a winner from training win rate alone.

The engine's stale-healing-target failure now records an explicit fizzle with no replacement target or healing credit. Only the one verified training `_find` failure repeat counter is retired during migration; historical failure totals and unrelated evaluation signatures remain. This does not certify all remaining simulator interactions.
