# Persistent future summons checkpoint

Scope remains the frozen regular Standard build 36.6.0.251952, with Mercenaries and Battlegrounds excluded.

Eight runtime declarations now cover the Animal Companion upgrade family and Void Soul family. Talya Earthstrider is registered; the other seven remain staged. Shared state and choices are connected to the four existing Companion consumers: Animal Companion, Call of the Wild, Spiritspeaker and Broll Bearmantle. This is a shared engine change, not independent scripts for every generated Beast.

Companion replacement rolls three stable identities from explicit exact-cost Beast contracts. Each later replacement uses the current identity's printed Cost. Existing minions are untouched. The candidate keeps these identities private to the owner; public counters record upgrades and extra summons. Talya adds one random companion per originating effect, so Call of the Wild summons four rather than six. Repeated Talya Battlecries stack, and the persistent benefit survives the minion leaving play. A selected Companion is followed by random bonus summons; selection is not Discover. Compact resumable counters preserve large bonus counts without silently truncating them. Full boards stop further summons.

Void Soul uses a persistent owner level, summons from the exact-cost Demon contract, then improves future copies. The same state applies to cards already held and cards generated later. Stardust Scythe grants a Soul after attacks, including its last swing; Vicious Voidscale grants one on death unless silenced. Void Blast shares a damage-outcome operation that awards its card after the death checkpoint, including lethal damage followed by Reborn. Its damage benefits from Spell Damage.

The candidate Void Soul level saturates at ten. Independent evidence for that boundary and precise upgrade timing is still required before live admission. Companion replacement into an empty successor pool raises an explicit error; no guessed maximum-cost fallback is substituted. All required Beast/Demon outcomes must be executable. Duplicate replacement weighting, visibility and event ordering also remain conformance gates. Migrating Elekk's printed frozen text includes Taunt although its mechanics array omits that tag; its runtime intrinsic keyword follows the text. Generated-pool metadata eligibility must include that discrepancy in review.

Creature of the Sacred Cave is also admitted in this checkpoint. Every Holy spell in the live registry was checked for supported internal casting. Its own-turn history and preferred-source targeting use the existing spell scheduler; this does not certify independent client event ordering.

Feature schema v43 adds public future-summon counters and owner-only Companion identities. The feature encoder explicitly ignores opponent Companion identities even if an invalid caller supplies them. Thirty-one new focused checks cover the family behavior; two additional feature privacy checks were added. Candidate STATUS.md records consolidated full-suite and smoke receipts.

Source context: frozen card records and numeric tags remain authoritative for this snapshot. The [Talya notes](https://hearthstone.wiki.gg/wiki/Talya_Earthstrider) describe random extra summons per effect; these are a secondary reference, not an independent client replay.
