# Friendly keyword auras

Arachnathid (JAIL_459) uses a shared FRIENDLY_KEYWORD_AURAS table. Keywords are evaluated from active friendly sources rather than permanently stored on recipients. Source Silence/removal removes the aura; recipient Silence does not remove a still-active external aura. Copies acquire the destination board's live aura instead of retaining it as an enchantment.

Six tests cover inclusion/exclusion, Rush/Poisonous combat, damage prevention, multiple sources, Silence, removal, copies and public observations. Source: pinned JAIL_459 metadata. General aura/death-phase timing remains subject to independent verification; removed entities do not receive this board aura.
