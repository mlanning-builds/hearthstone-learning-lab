# Fixed historical summon spell recipes

Nine historical spell bodies use literal frozen token recipes: Vile Call,
Thorngrowth Sentries, Coordinated Strike, Command the Illidari, Mirror Image,
Dreamway Guardians, Kara Kazham!, Immortalized in Stone, and Sneaky Snakes.
The shared Illidari recipe uses `BT_036t`. Multi-token recipes preserve printed
order: Candle, Broom, Teapot; and 4/8, 2/4, 1/2 Statues.

The original Immortalized in Stone shares the current Core canonical identity
and is excluded from past-era membership checks.

Twelve distinct fixed token identities accompany these spells. They are not
historical collectible pool members or Standard deck entries. Printed stats,
tribes and keywords come from the unchanged frozen archive, each bound to its
reviewed metadata hash. Runtime execution does not interpret text.

Seven focused checks exercise every recipe, exact physical identities and stats,
paid spell consumption, one remaining slot, full boards, generated-only registry
membership, Lifesteal, Rush restrictions, Taunt and Stealth. These checks do not
approve any historical random pool or independently certify client ordering.
