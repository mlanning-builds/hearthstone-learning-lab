Use legal setup steps and record provenance; if a setup is synthetic, label it separately and never present it as a client trace.

## Evidence quality and current status

All twelve scenarios remain **independently unverified for the pinned build**. Card text identifies the intended feature, not every timing detail. Current source and tests document our implementation, not an external oracle.

Blizzard's [12.0 mechanics explanation](https://hearthstone.blizzard.com/en-us/news/21965466) is primary historical evidence for zone/copy enchantment behavior. It distinguishes forward zone transitions and copying from resurrection and transformation. It was published in 2018, so it does not certify every interaction in this 2026 target. Keep it as a starting rule reference with explicit version scope.

The existing wiki references in project documents remain references to review. Attempts to fetch the Advanced Rulebook and Summon pages in this block returned HTTP 403; no new claims are attributed to unread page contents. Historical open-source implementations can suggest cases but are not authoritative target-patch results.

If a scenario exposes a disagreement, retain both the expected trace and simulator replay. Correct the shared rule before expanding its dependent cards. No pass mark is earned by editing the expected outcome to match our implementation.
